## Correctness

| ID | Finding | Sev | Why It Matters |
|----|---------|-----|----------------|
| F4 | ChainAnalyzer's rerouted catch handlers can still drop QRY900 silently. (a) `first?.Bound.Raw.Location ?? default` (src/Quarry.Generator/Parsing/ChainAnalyzer.cs:117-120, 209-212, 241-244) yields `FilePath == null` when the site list is empty; the group filter `d.Location.FilePath == filePath` (src/Quarry.Generator/IR/PipelineOrchestrator.cs:501-503) then matches no group and the diagnostic vanishes (and even if reported, `CreateLineLocation` returns `Location.None` for `line <= 0`, src/Quarry.Generator/QuarryGenerator.cs:887). | F5 | The Stage 4 translate catch (src/Quarry.Generator/QuarryGenerator.cs:154-159) still catches `OperationCanceledException` and records it as `TranslatedCallSite.PipelineError`, while the adjacent Stage 3 catch now excludes it (QuarryGenerator.cs:120). | F6 | The `diagnostics` parameter of `ChainAnalyzer.Analyze` is still optional and the catch handlers use `diagnostics?.Add` (src/Quarry.Generator/Parsing/ChainAnalyzer.cs:117, 209, 241).
